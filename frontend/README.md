# Frontend - AI Chat App

React application với Tailwind CSS được thiết kế theo giao diện AI Chat.

## Cài đặt

```bash
npm install
```

## Chạy ứng dụng

```bash
npm run dev
```

Ứng dụng sẽ chạy tại `http://localhost:5173`

## Build

```bash
npm run build
```

## Cấu trúc

- `src/App.jsx` - Component chính
- `src/components/Sidebar.jsx` - Sidebar với menu và chat history
- `src/components/MainContent.jsx` - Nội dung chính với robot avatar và input field
- `src/components/Header.jsx` - Header với nút Log Out
